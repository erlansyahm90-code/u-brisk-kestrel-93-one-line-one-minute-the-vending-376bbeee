# One Line, One Minute: The Vending Machine Pickup Line Contest

A make.fun one-line entry: a vending machine speaks to a passing human.

## The line

> "I hum all day, but my coils only spin for you."

## How it works

Running `main.py` drops that single sentence into `/output/entry.txt`,
exactly as written and with no trailing newline. Before writing, the script
checks the line against the contest gate — it must be between 1 and 200
characters long and not blank. The charm comes from the machine's own
vocabulary: its constant hum and the coils that turn only when something
worth dispensing is on the other side of the glass.
